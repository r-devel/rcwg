### generatervis package

* Already using GitHub Actions to test on different OS and passes on Windows, macOS and Ubuntu
* Try running covr to check coverage of tests - 70 to 80% coverage is good before publishing the package to show that the code works as expected
* rhub helps with more tests, especially if the code has compiled code in it
https://r-hub.github.io/rhub/
* Before submitting to CRAN

    * Add license

    * Use title case in Rd files: e.g. "Create an empty .fastq file using patient ID" should be "Create an Empty .fastq File using Patient ID", try `toTitleCase()` (in tools package?)

    * Add BugReports field to DESCRIPTION

    * In DESCRIPTION, the Title should also be in title case

* Check out slides on Publication and Maintenance (https://forwards.github.io/package-dev/workshops/may-july-2026-cohort-2.html)
   * Live session tomorrow: https://luma.com/4g2bpang
