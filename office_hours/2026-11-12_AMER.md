## Discussion

### int64

* Mikael is working on support for sparse matrices with number of non-zero entries > 2^31. This is in the Matrix package and independent of what support is eventually offered in base R.

### R CMD exec

* Idea is that command line interfaces provided by packages in the `exec` folder could be run with `R CMD exec` passing arguments as command line arguments directly (rather than using Rscript to run R functions)
    * Would require package authors to write the wrapper code that would then convert to R function arguments - better than expecting users to do this.
    * Users would need RTools
    * Not limited to R scripts, could be shell scripts there
    * Could be useful in pipelines, like Galaxy workflows
    * Quality control is an issue - but was already possible in a convoluted way.
        * For an R script, it should certainly be parsable and checked for usage of undeclared dependencies.
        
### preprocessor

* Gabe would like to propose a preprocessor
    * Possibly could be used to generate a CLI via macro style annotations on scripts
        * R.app package does something along these lines: https://github.com/r-lib/Rapp
        * There is also https://cran.r-project.org/web/packages/getopt
    * How to make the proposal for a preprocessor?
        * An enhancement proposal process was on the roadmap for the RSMF project, but not near starting yet
        * Could propose at R Project Sprint 2027
            * Probably want to share something in advance, particularly as not all R Core members will be there
            * Then discuss and refine at sprint
        * Gabe can work with Heather and Ella, starting to formulate ideas about a proposal process, maybe with this as an example/pilot

* Other ideas that were proposed at R Project Sprint 2027
    * Seems like there was general support for classed error hierarchy
    * This has the bonus of potentially providing a simpler solution for untranslating error messages (which otherwise is too hard a problem with not enough gain to justify spending time on).
    * Gabe will try to follow up with Luke to see if this can be carried forward and what sort of timescale is reasonable, e.g. R 4.7 or later.
