   * Work in progress on branch of rhelpi18n package: https://github.com/adit-0132/rhelpi18n/tree/module-skeleton

   * Drafted vignettes describing the workflows:
     
        * Users: https://adit-0132.github.io/multilingual-docs/guide-users.html

    * Discussion:
    
        * Maybe should be using `Sys.setlanguage()` instead of `Sys.setenv(LANGUAGE="es")`
        
        * Downside of using placeholders is that translators cannot see expression that would be substituted which might be useful information. Maybe can carry forward verbatim text in some way, maybe as another YAML entry.
        
        * We are using a separate package for translations as they might be maintained by different people from the original package and users only need to install the translations they need.
        
        * What happens if two packages have the same function? Help system has disambiguation - need to check if this works.
        
        * Check does not affect help for other packages that don't have translations.

    * Will share with people for testing when merged in current work in progress, will take on board comments above.
